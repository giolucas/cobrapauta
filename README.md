# CobrePauta

Landing page do CobrePauta: acompanhe as pautas que você defende e cobre quem pode agir por elas.

Site estático (HTML + CSS + JS puro, sem build). Para ver localmente, abra o `index.html` ou rode:

```bash
python3 -m http.server 8000
```

## Estrutura
- `index.html`: seções (hero, por que importa, proposta, como funciona, passos 1–3, ranking/linha do tempo, ação, fontes de dados, CTA)
- `styles.css`: design (roxo `#6D3FE8`, tinta `#2A1B5C`, fonte Open Sans)
- `app.js`: interações e **dados de exemplo** (`PAUTAS`, `PESSOAS`, `RANKING`, `ETAPAS`). Nomes, partidos e projetos são fictícios; troque pelos dados reais quando estiverem disponíveis.
